# New Review Phase

Create only Repository-specific Reviews that close evidence-backed gaps already presented in the ordered proposal list.

For each proposed Review:

1. Draft the complete Review: name, description, applicability rule or `null`, required execution configuration, and ordered Criteria with advisory or blocking impact.
2. Tie every Criterion to repository evidence and an observable code-quality failure.
3. Show the complete draft in one plain-language, decision-ready block.
4. Ask the user to approve, revise, or skip this Review.
5. Create it only after approval. Verify its assignment contains only the bound Repository.

Keep Criteria independent and testable. Use blocking impact only when a violation should make the Evaluation blocking. Every created Review must address a current evidence-backed gap.

Complete the phase when no proposed Review remains undecided.
