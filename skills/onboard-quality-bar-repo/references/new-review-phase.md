# New Review Phase

Create only repository-specific Reviews that close evidence-backed gaps.

For each proposed Review:

1. Draft the complete Review: name, description, applicability rule or `null`, Codex configuration, and ordered Criteria with advisory or blocking impact.
2. Tie every Criterion to repository evidence and an observable code-quality failure.
3. Show the complete draft in one decision-ready block.
4. Ask the user to approve, revise, or skip this Review.
5. Create it only after approval. Verify its assignment contains only the bound Repository.

Keep Criteria independent and testable. Use blocking impact only when a violation should make the Evaluation blocking. Do not create placeholders, generic best-practice Reviews, or future-facing scaffolding.

Complete the phase when no proposed Review remains undecided.
