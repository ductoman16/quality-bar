Design System

A warm monochrome LCD language in one geometric-mono voice — soft outlined cards for dashboards, flat hairline rows for lists.

  • One voice. A single geometric-mono face (Aeonik Fono) carries titles, labels, and values alike.
  • Warm & pale. One cream-sage canvas, one warm ink; the only "color" is emphasis.
  • Cards group, rules list. Soft outlined cards (no fill) group dashboard data; hairline rows carry scannable lists and ledgers.
  • Round where you act. Controls are soft (8px), toggles and icon buttons are round — the surfaces you touch feel physical.
  • Big, confident numbers. Values are the loudest thing on the screen. Secondary actions never shout.

Components · Buttons

Primary

The single most important action on a view — create, save, confirm. At most one per screen.

Secondary

Supporting or reversible actions that shouldn't compete with the primary — Cancel a run, Retry, Restore an archived review. Outline that darkens on hover.

Compact

Any variant, shrunk for dense rows and toolbars — inline row actions like Cancel, Retry, Add criterion.

Links, not buttons

Navigation and inline actions are plain underlined links — never outlined buttons. The underline is the whole affordance.

Components · Metric dial

Headline rate

One hero dial per view, for a single rate whose goal is a full/ideal value and where "toward 100%" is the point — e.g. Review-run success on Analytics. The stat strip and trend still carry every detailed rate; the dial just makes the one number that matters land at a glance. Never one-per-rate — and not for things better read as a count (a near-full dial buries the exceptions; a "Health errors: 1" count surfaces them).
