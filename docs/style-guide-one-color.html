Accent

Agent Review System · Design System

One Color · Dark & Light

The Fono language, unchanged in structure — one geometric-mono voice, shapes that carry meaning, a strict monochrome base — in a warm-dark or light canvas, each granted exactly one accent color. Pick the accent and flip the mode above.

  • Same bones. One mono voice; big confident values; soft outlined cards group, hairline rows list; round where you act.
  • Shape still carries outcome. Square system phase, circular Review node, cross-hatch blocking, triangle advisory — geometry means what it always did.
  • One color = "live & actionable now." The accent appears only on the single primary action, the active nav item, the ON toggle, the gauge arc, the running node, and the focus ring.
  • So color and shape never compete. Danger stays monochrome and shape-driven; the accent is rare, so wherever it glows it means something.

The neutrals aren't fixed — each holds its own lightness exactly and borrows only the accent's hue, a near-grey tinted but never lightened or darkened, so the base retones with the one color while contrast stays identical for every accent. Pick Amber and the charcoal warms to olive; pick Cyan and it cools to slate. Everything follows from a single hue — swap the accent in the picker above and watch the canvas, ink, and rules shift with it.

The rule · where the one color may live

Accent may touch

  • The one primary action per view
  • Active nav item & focus ring
  • ON toggle & the gauge progress arc
  • The currently-running node / live pulse

Accent must not touch

  • Outcome glyphs — Clear, Advisory, Blocking, Error (shape carries these)
  • Body text, labels, values, or table data
  • Card fills, borders, or hairline rules
  • More than one primary action on a screen

The fork: this doctrine makes the accent mean go / live / act. If you'd rather it mean needs you, move it onto Blocking & Error only and keep primary actions monochrome — quieter overall, but the toggle, gauge, and running pulse lose their glow. You can't have both without the color losing its meaning.
